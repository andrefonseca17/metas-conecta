Como atualizar com o Trello
  1. No quadro, abra o menu (⋯) → Imprimir, exportar e compartilhar → Exportar como JSON.
  2. Salve o arquivo e clique em Importar JSON do Trello aqui (ou arraste o arquivo para esta página).
  3. O que você marcou no app (etapas, status, resultado, pesos) é mantido. Cartões e checklists novos entram automaticamente.

O app lê cada lista com um percentual no nome (ex.: "Servidores 5%") como uma meta com aquele peso.
